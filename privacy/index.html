Tesla Speed プライバシーポリシー

最終更新日: 2026年10月3日

Tesla Speed(以下「本アプリ」)は、Tesla社の公式 Fleet API を利用して、ユーザー自身の車両の現在速度を表示するアプリです。本ポリシーでは、本アプリが扱う情報とその取り扱いについて説明します。

1. 取得する情報

  • Teslaアカウントの認証トークン: Teslaアカウントでのログイン時に Tesla社から発行されるアクセストークンおよびリフレッシュトークン。
  • 車両情報: 車両一覧(車両名・VIN・ID)と、走行状態(速度・シフト状態など)。Tesla Fleet API の仕様上、走行状態の応答には車両の位置情報が含まれる場合があります。

本アプリは、Teslaアカウントのパスワードを取得・保存しません。ログインは Tesla社の認証ページで行われます。

2. 利用目的

取得した情報は、本アプリの画面に車両の速度を表示する目的にのみ利用します。広告、分析、プロファイリングには利用しません。

3. 保存場所と保存期間

  • 認証トークンは、ユーザーの端末内に Android Keystore で暗号化して保存します。ログアウトまたはアプリのアンインストールで削除されます。
  • 車両情報・速度・位置情報は表示のためにメモリ上で一時的に扱うのみで、端末にも外部サーバーにも保存しません。
  • 端末のバックアップ(クラウドバックアップ・端末間移行)の対象から除外しています。

4. 第三者への提供・外部送信

  • Tesla社: 車両情報を取得するため、Tesla Fleet API と通信します。
  • トークン中継サーバー(Cloudflare Workers): ログイン時およびトークン更新時に限り、認可コードまたはリフレッシュトークンを開発者が運用する中継サーバーに送信し、Tesla社とのトークン交換を行います。中継サーバーはトークンを保存せず、ログにも記録しません。

上記以外の第三者に情報を提供・販売することはありません。通信はすべて HTTPS で暗号化されます。

5. 車両の操作について

本アプリは読み取り専用の権限(vehicle_device_data)のみを要求し、施錠・解錠・発進などの車両操作は行いません。ユーザーの操作により、スリープ中の車両を起動する要求を送信する場合があります。

6. アクセス権の取り消し

本アプリ内の「ログアウト」で端末上のトークンを削除できます。また、Teslaアカウントの設定(accounts.tesla.com)から、本アプリへのアクセス許可をいつでも取り消せます。
